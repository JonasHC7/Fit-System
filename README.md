Fit System 🥗💪
  O Fit System é um aplicativo simples desenvolvido em Python com Tkinter para auxiliar usuários na escolha de uma dieta personalizada e no cálculo do Índice de Massa Corporal (IMC).

📌 Funcionalidades
  📊 Cálculo do IMC com base no peso e altura informados.
  🍽️ Sugestão de dietas personalizadas conforme idade, peso, altura e presença de doenças como diabetes, colesterol alto ou pressão alta.
  ✅ Interface intuitiva construída com Tkinter.
  🔚 Opção para finalizar o aplicativo.
  🛠️ Tecnologias utilizadas
  
Python 🐍
  Tkinter (para interface gráfica)

🚀 Como usar
  Execute o arquivo python nome_do_arquivo.py.
  Insira seus dados: nome, idade, peso e altura.
  Escolha se possui alguma condição de saúde.
  Clique em Calcular IMC para ver seu Índice de Massa Corporal.
  Clique em Calcular Dieta para receber uma recomendação personalizada.
  Para fechar o programa, clique em Finalizar APP.

📌 Este é um projeto básico e pode ser expandido com novas funcionalidades no futuro!
